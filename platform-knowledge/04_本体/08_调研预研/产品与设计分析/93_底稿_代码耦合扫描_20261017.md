> 生成日期：2026-10-17。方法：只读扫描 backend（Go+Eino ADK 主平台）、ontology-service / runtime-manager（同仓库另两个 go module）、web/src（前端）；所有结论附文件路径+行号或 grep 计数；无法从代码推断的标「待确认」。
> 评级口径：**S0** 独立（零被依赖/纯测试消费）｜**S1** 旁路可摘（HTTP 边界或装配点集中 1–2 文件）｜**S2** 编译期依赖（≥2 文件 import 或挂进装配链）｜**S3** 侵入主体核心（主对话链路 struct 直接持有具体类型+多方依赖网）。

## 0. 仓库模块拓扑（耦合分析的前提）

仓库为多模块 Go workspace（go.work）：

| 模块 | 角色 | 端口 | 与 backend 的耦合方式 |
|---|---|---|---|
| `backend/` | 主平台（API+对话+KB+KG+伴生） | :8080 | 本体（本体构建平面/运行平面）经 **HTTP 反代**，无跨模块 import |
| `ontology-service/` | 本体构建平面（含 OntoChat 引擎等借鉴实现大本营，48 个非测试 .go） | :8091（BUILD_SVC_URL） | 对 backend 为 **HTTP 边界**；跨模块 import 计数=**0**（grep `eino-multiagent-lab/backend` 仅 5 处注释命中：`internal/rest/rest_nl2sparql.go:4-5,30`、`internal/toolchain/toolchain.go:5`、`internal/toolchain/lifecycle.go` 附近，均为口径对齐说明，非 import） |
| `runtime-manager/` | 本体运行平面（facade/SPARQL/方案） | :8090（RUNTIME_MGR_URL） | 同上；grep semantica/ontochat/cqbench/ontorag/ontoextend **0 命中** |
| `web/` | React 前端 | - | 仅消费 `/api/*` |

**关键结论**：任务背景中提到的 ontorag/cqbench/qualitygate/ontochat/ontoextend/evaldata 等「借鉴实现」的真实落码大本营在 `ontology-service/internal/`（同仓库、独立 go module），backend 侧通过 `internal/ontology` 反代接入；backend 内自研落码的借鉴实现是 companion、kg、kb、ontobuild、agenteval 五族。**backend 与 ontology-service 之间零 import 耦合**（`toolchain.go:6` 明示：「本包独立实现以避免跨 go module 依赖」）。
