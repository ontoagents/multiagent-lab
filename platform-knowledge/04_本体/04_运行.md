## 定位与能力现状

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 方案管理 | ✅ | 引擎分组导航（Oxigraph/Fuseki/oo 引导/Cayley 占位 disabled）+方案卡网格+三步新建向导+启停/重载/编辑（停止态）/删除；引擎自检 5s 轮询+一键安装（REQ-146 pin v0.5.11） |
| 执行方式 | ✅ | 系统级 runtime_config：**默认 docker，未安装 docker 启动期自动降级进程内 native**（D-O20 v0.73 变更；配置值不写回，`effective_method` 透出实际生效）；k8s 接口预留。oxigraph native/docker（容器 rt-{id}，**端口映射绑 127.0.0.1**）；fuseki native+推理开关（docker 化未做） |
| 启动对账 | ✅ | 服务重启后 DB running 逐一探测：docker 容器领养/native 引擎领养（facade 句柄恢复）/失活收敛 stopped（REQ-236①）——真机 4 方案全领养验证 |
| 端口分配 | ✅ | bind 试探占用跳过（9201+ 动态段，REQ-236③） |
| facade 契约 | ✅ | /mcp **6 个只读 onto_* 工具**（get_concept/get_instance/list_instances/neighbors/list_concepts/sparql_query）；RunningByOntology 最早创建确定序路由；guide 紧凑口径；翻译透视 trace 落库可查 |
| SPARQL 工作台 | ✅ | 方案详情 Drawer 内 CM6+AntD 自组装（模板/CSV/⌘⏎/持久化）；**服务端只读 SELECT 白名单兜底**（与 facade 同口径，REQ-236⑥） |
| 装载质量快照 | ✅ | Start 异步快评（quality/check save=false 零副作用）→方案卡低分橙标（overall<80 或 error>0，REQ-234①） |
| 日志 | ✅ | 引擎 stdout 落盘+tail 200（NFR-O-5） |

生效语义：仓库保存新版本后**显式重载**生效（REQ-87 教学点）；drift 由 loaded_versions+lifecycle plan 检测（REQ-155）。运行期数据不持久（Start 重建数据目录是设计使然；伴生数据走独立快照机制例外）。

- 前端：`RuntimePage.tsx` + `SparqlWorkbench.tsx`
- 后端：`runtime-manager/internal/{store,manager,engine/oxigraph,engine/fuseki,facade,rest}`；迁移 001~007（004 历史缺号）
