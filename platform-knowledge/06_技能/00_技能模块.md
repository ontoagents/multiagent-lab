# 技能（Skill）

## 产品定位

技能 = 可复用的能力包：**一段领域指令 + 一组可选工具**，创建一次、多个 Agent 复用。让"怎么做某类事"的知识与配置解耦于具体 Agent。

## 设计原理

- **结构化技能包**（对齐 Claude Skills 思路）：`{name, description, instruction, tools[], resources?}`——instruction 在装配期追加进 Agent 系统提示词，tools 并入 Agent 工具集（与勾选工具先到先得合并）。
- **两级开关**：Agent 配置里勾选挂载哪些技能（挂载级）；对话输入框的「技能」chip 控制本次会话是否注入（会话级 `enable_skills`，默认开）。
- **不做技能运行时**：技能是配置级能力包，不是代码执行环境——不沙箱、不解释执行；"让 Agent 用得对"靠 description 与 instruction 写清楚。
- **过程可见**：运行事件标注技能注入（skill.loaded），对话里能看到本 Agent 本次启用了哪些技能。
- **目录式技能包导入**（REQ-371，2026-10-22）：技能页头部动作区「导入技能（.zip）」（与「新建技能」并排；同日迭代自「更多」弹层上移）批量解析业界 Agent Skills 标准包（SKILL.md + frontmatter + 同目录附加资源）——frontmatter name/description→Name/Description、正文→Instruction（`load_skill` 懒加载正文承载）、同目录文本文件→Resources（REQ-120 字段存储，注入消费留 P2）；`allowed-tools` 等工具面字段不映射平台工具注册表（置空，由使用者在平台内勾选）；**同名跳过不覆盖**（沿配置导入口径）；导入防线（解压总量/技能数/正文与资源限额）超限随报告诚实标注不静默。首批已导入 [k-dense-ai/scientific-agent-skills](https://github.com/k-dense-ai/scientific-agent-skills) 177 件科学技能包（MIT）。
- **技能集合（一卡多子技能）**（REQ-373，2026-10-22）：页面建一个「集合」，智能体挂载集合即启用其下全部子技能——装配层按启用成员展开目录（各子技能独立目录行 + `load_skill` 懒加载，**保留各自描述的触发粒度**），工具白名单取成员并集；集合无自身指令、不嵌套（成员须普通技能）；删除成员自动摘除集合引用；技能包导入支持「按包归集」（`collection_name`，新建件收进一卡，跳过/失败不入集）。入口=技能页「新建技能」分裂钮箭头菜单「新建技能集合」。
