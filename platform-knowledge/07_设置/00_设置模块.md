# 设置（模型连接与推理后端）

## 产品定位

设置是全平台"用哪个模型"的唯一配置入口：维护模型连接（对话 chat / 向量 embedding）、设默认、看使用统计、查推理后端。所有模块（智能体对话、知识库向量化、本体 AI 创建、KG 抽取）都引用这里配置的连接，不自带密钥。设置页现承载的分区：**模型管理**（本节主体）+ **连接器**（外部能力接入，REQ-214/416）+ **协议**（MCP/A2A 协议面总览，REQ-418）+ 实用工具入口（诊断包/备份恢复，REQ-410/411）；平台助手配置已归一智能体侧（REQ-213，本页助手分区已删）。

## 设计原理

- **双协议接入（REQ-172）**：`openai_compat`（OpenAI 兼容，/chat/completions——任一厂商提供兼容端点即可接入）与 `anthropic`（Anthropic Messages API，/v1/messages——官方与 DeepSeek/智谱 GLM/Kimi 等厂商的 Anthropic 兼容端点）。协议是连接级属性，Agent 对话/结构化生成/平台助手按所用连接的协议自动分流到对应通道；anthropic 仅支持对话模型（Anthropic 无官方向量接口），BaseURL 填网关根地址、平台自动拼接 /v1/messages，温度按 Anthropic 温度域 [0,1] 钳制。连接 = 名称 + 类型 + 协议 + BaseURL + 模型名 + API Key。**协议归属（REQ-177）**：协议是连接属性而非供应商身份——同一供应商组内可同时存在 openai_compat 与 anthropic 连接，供应商列表/下拉只显示供应商名（协议标签在模型行），编辑提供商只批量应用身份字段（名称/别名/Key/启用），协议与 BaseURL 在「添加/编辑模型」逐连接维护。
- **平台助手（REQ-166/177③）**：内置系统级 Agent（不占智能体列表、不可删），为「AI 优化」按钮提供模型与提示词；系统提示词已预置内置默认（按平台定位：七模块答疑/内容优化约束完整/配置辅助）。**配置已完全归一智能体侧（REQ-192/M32 单源化 + REQ-213 出口归一）**：助手配置收敛智能体内置行（builtin-assistant）**单源**，配置入口=智能体页侧栏内置节点「⚙ 配置」打开的配置侧板（身份字段只读、内置基座八工具 L0/L1 禁选不可摘除、白名单 8 字段可编辑：提示词/模型/温度/tools/skills/MCP/max_tokens/max_iteration）；**设置页「平台助手」分区已删除**（REQ-213，旧深链重定向「模型管理」），本页不再承载助手配置；助手对话中 propose_assistant_config 产出的配置提案在配置侧板横幅确认（两段式）；「AI 优化」的调用记录落助手名下「内容优化」会话（来源标注，历史还原可见）。
- **厂商预设 + 自动发现**：添加提供商时从预设（Anthropic 官方及 DeepSeek/智谱/Kimi 的 Anthropic 兼容端点、DeepSeek/百炼/千帆/智谱/Kimi/硅基流动/MiniMax/星火的 OpenAI 兼容端点）一键填充协议与 BaseURL，补 Key 即可；保存后自动挂"自动获取模型"面板，从接入点拉取可用模型批量建连（Key 归提供商共享；anthropic 走 /v1/models）。**本地模型预设（REQ-408② ✅ M204，2026-10-24）**：预设池补本地 OpenAI 兼容端点（Ollama 等），零 API key 可跑通——配套首启向导见智能体模块（OnboardingGuide）。
- **连接器（REQ-214 ✅ M46，2026-09-30）**：agent 连接外部能力（外部 MCP server / Kubernetes / SSH）统一为「连接器」产品概念——设置页「连接器」分区与模型管理平级：三类型实例 CRUD + 凭据 AES-256-GCM 加密托管 + 连接测试；K8s/SSH 由平台托管自研 Go MCP 插件服务承载（进程内嵌 loopback :8093：kubectl CLI 包装四工具 + x/crypto/ssh exec-per-call，非零 exit code 透传）；装配期 `{连接器实例名}__{tool}` 前缀改名；agent 侧授权=智能体侧板「能力」页签连接白名单（智能体模块同记）；内置 open-ontologies 连接器。
- **A2A 连接器（REQ-416 ✅ M212，2026-10-24）**：连接器扩 `kind=a2a`——create 即真握手拉取 `/.well-known/agent-card.json`（不可达 400 如实拒绝），卡片原文落库（迁移 065 card_json）+ tools=对端技能名；probe / test / preview 三点；外部 A2A 成员经 agent_as_tool 协作面被委派（message/send + tasks/get 轮询 + artifacts 回传，详见智能体/项目模块档）。
- **协议面总览（REQ-418 ✅ M214，2026-10-24）**：设置页「协议」分区 ProtocolPane 三页签——MCP 服务面接入指引 + A2A 发现与 agent card 预览 + A2A 任务列表可视（/api/a2a/cards · tasks）；会话内协议路径标识（内部 / A2A 外委派区分 + 连接器来源徽标）。
- **诊断自助包与备份恢复（REQ-410/411 ✅ M206/M207，2026-10-24）**：设置页实用工具入口——一键诊断 zip（healthz 快照+最近错误+脱敏配置）与一键备份（VACUUM INTO 三库+伴生图+agent-files）+ 恢复入口。
- **默认连接机制**：chat / embedding 各至多一条默认；智能体"跟随全局默认"即引用它。首次启动预置 DeepSeek 对话连接与百度千帆 embeddings-v1 向量候选（填 Key 启用即默认）。
- **Key 安全**：AES-256-GCM 加密存储，界面仅掩码回显，密钥文件与数据库都不进仓库；引用保护——被引用的连接删除/停用有明确提示。
- **使用统计**：按模型/供应商/智能体/项目聚合调用次数与 token 消耗（数据来自运行事件的 usage）。
- **推理后端探测**：eino-adk 恒可用（默认），外部 CLI 后端按 PATH 探测（缓存 10 分钟），能力矩阵如实标注。
