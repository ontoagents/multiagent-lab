## 30 秒判断「我的新文档放哪」

- 描述「系统**现在是什么样**」→ `handbook/`（对应模块子目录，编号沿目录内惯例）
- 记录「**为什么这么做**/调研/评审过程」→ `research/`（编号方案档沿各模块惯例）
- 需求/进度/治理记账 → 根级编号档（领号先查 18 号注册表；状态当轮同步 19 号索引）
- 教学向浓缩解释 → `learning/`
- ⚠️ 拿不准时：过程稿先落 `research/`，成熟后再提炼进 `handbook/`——现状类宁缺勿滥，防止 handbook 重蹈膨胀
