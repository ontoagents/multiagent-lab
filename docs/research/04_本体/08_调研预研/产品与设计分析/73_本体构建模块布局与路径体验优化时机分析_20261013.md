## 1. 「拥挤」的量化与成因：真问题，且有明确的近期成因

**量化事实**：`BuildPage.tsx` 1028 行，其中 S1Source 单组件约 **600 行**（58%）承载五来源 Tab（导入文件/AI 创建/内置示例/空白新建/由知识库构建）。AI 创建 Tab 经连续加塞已形成 **8+ 内容块单列纵向堆叠**：

```
CQ 标题行（手写说明 + AI 生成按钮）  ← REQ-90/308
CQ 手写 TextArea
CQ 候选确认卡（REQ-308，条件展开）
领域描述 TextArea
额外提示 Input
澄清卡（REQ-306：复述+五维缺口+补充输入+三按钮+轮次计数，条件展开）
生成按钮 + 实测轮次进度             ← REQ-267/295
结果预览（三计数 Tag + warning + 名称输入 + 保存）
+ REQ-312 待领取将再加：质量报告卡 + 按报告优化按钮 + 新旧对照 ≈ 11 块
```

**成因**：REQ-248（CQ 引导）→267（异步+质量分）→295（进度）→306（澄清卡）→308（CQ 卡）→312（报告卡，待领取）——三轮内连续往同一个单列表单里加能力块。**拥挤不是历史债，是活跃需求在旧容器上的堆积**——这正是「该优化了」的最强信号：再交付 REQ-312 而不动布局，体验会继续恶化。

**原则违背**：17 号产品原则 P2「渐进披露——每层界面只暴露当前阶段需要的能力，不铺满首屏」——现状 CQ/澄清/生成/预览全部平铺，靠条件展开兜底，首屏密度超标。

## 2. 「每种构建类型都简陋」的分级评估：不完全成立，逐路径看

| 路径 | 体验现状 | 判定 |
| --- | --- | --- |
| OntoChat 流程 | 八阶段状态机+访谈+确认卡+过程可视化+自由问答槽（870 行，最完善） | **不简陋**（平台标杆） |
| AI 创建（自定义构建子 Tab） | 能力密度已高（澄清轮/CQ 生成/异步/质量分）但布局仍是**单列表单堆叠** | **是过载不是简陋**——与拥挤同源同修 |
| 导入文件/粘贴 | 拖拽+格式嗅探+体积预检（REQ-305） | 够用，简陋度低 |
| 由知识库构建 | 三策略配置表单（584 行）——功能中等，长表单无过程引导 | **真偏简陋**（中等优先级） |
| OntoExtend | 307 行引导卡 | 简陋但是**定位使然**（诚实口径「引导卡，工程化入需求池」），不算欠账 |
| 空白/内置示例 | 极简 | 合理 |

## 3. 时机判断：**到了，但分级优化**——局部重构紧迫，IA 重排可触发驱动

**判断依据四信号**：①新功能被迫挤进旧容器（命中，近三轮）②已知需求将再加重（命中，REQ-312）③路径间体验落差影响整体观感（部分命中）④违背自身 IA 原则（命中，P2 渐进披露）。

**P1（紧迫，建议随 REQ-312 领取时同批实施——布局级重构，不动业务逻辑）**：
- **AI 创建 Tab 两栏化**：左列=建模输入（CQ 区/描述/提示/生成按钮，顺序即操作顺序）；右列=反馈与产出（澄清卡/CQ 候选卡/质量报告卡/预览确认）——加塞三轮的块天然分属「输入」与「反馈」两类，两栏各自恢复呼吸感，REQ-312 报告卡正好落在右列；窄屏降级单列。
- **渐进披露收口**：澄清卡/CQ 候选卡保持条件展开（现状）；生成结果区默认收起为「最近一次生成状态条」，展开看报告卡与预览——首屏只留输入面。

**P2（触发驱动，需先拍板 IA 口径）**：
- **AI 创建提为一级路径卡**：17 号 §2.2 分类学口径=「来源×交互形态」正交——AI 创建目前挂在「自定义构建（人类手工）」路径下作为 S1 子 Tab，分类学上它属于「AI 单轮+微对话生成」形态，与 OntoChat（对话形态）并列更自洽；但提级会动「六路径对照」教学叙事与用户习惯，且 REQ-306 A2 已做入口分流兜底——**收益中等成本中等，建议 P1 落地后看使用反馈再议**。
- **各路径统一骨架**：路径头（定位说明+前置条件）→引导区→工作区→产出区四段式模板化，KB 构建先行试点（真偏简陋的那条）。
- KB 构建向导化（选库→策略→CQ 模式→草稿的步骤化）随其下一次功能需求顺带。

**不做/观察**：全模块布局推倒重来（无此必要——问题集中在 AI 创建 Tab）；OntoExtend 工程化（已有需求池口径，定位未变不欠账）。

## 4. 判定口径沉淀

「页面拥挤+体验简陋是否该优化」的评估顺序：①拥挤先找成因——如果是活跃需求在旧容器堆积（而非历史债），优化紧迫度高且应与下一个相关需求同批（省一次回归）；②「简陋」逐路径判定——过载（功能多布局差）、真简陋（功能少体验糙）、定位性简陋（引导卡定位）三种处置完全不同；③IA 级重排（路径提级/分类学调整）必须过口径事实源（17 号）与教学叙事影响评估，与布局级重构分级处理。
