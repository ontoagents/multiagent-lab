- **不收什么**：各模块「当前实现状态」（→ `docs/handbook/<模块>/`）、需求事实源与进度账本（→ `docs/` 根级编号档）、学习资产（→ `docs/learning/`）。

## 命名规范（REQ-188，沿用；前缀仅排序不驱动页面）

1. **目录**：`NN_名称/`——NN 两位数字决定目录内排序；`08_调研预研/` 为各模块调研预研专区的保留目录名（收录判定口径见 [08_调研预研/00_调研预研.md](08_调研预研/00_调研预研.md)）。
2. **文件**：`NN_名称.md`——`_` 只作「前缀-名称」分界：
   - `00_` 保留给专区/专题主页（目录内置顶）；
   - **全局编号档**沿用 docs/18 注册表全局号（如 07/08/13/19/21/22/23/24/25/26/27），编号不回收、不重编；
   - **本地排序档**用 **31~99 号段**（避免与全局 01~27 号段混淆），目录内插空取号（本地号段用满后自然顺延 100+，首例=04_本体/08_调研预研/产品与设计分析/100 号）；
   - 文件名不带日期后缀为收敛方向；存量带日期后缀档（64 档）暂不追改，命名收敛另轮（113 号 §7 开放问题 1）。
3. **frontmatter**：过程档不强制补齐，沿现状（新档建议仍带 `module`/`topic`/`desc`/`synced` 四字段，便于后续检索面接入）。

## 收录规则（保留正文）

1. 新增主题档：按命名规范落入对应目录；**本目录不入前端页面**，无需考虑页面树与 icon。
2. **收录定位（2026-09-29 开发者规则）**：**已采纳、开发的方案文档才放各模块目录**；未拍板/未落实的方案、预研调研、立项依据档放 `08_调研预研/`（含目录内 00_ 主页的判定口径表）——对应需求拍板开发交付后迁回内容归属的模块目录，编号不变。已废弃但有归档价值的方案留在原目录并保留废弃注记，不迁移。
3. 四区收敛后（2026-11-01）：批次 1 起新方案档/调研档直接落本目录；拍板进入实现后的**现状**同步义务指向 `docs/handbook/`（AGENTS.md 纪律 7），本目录只追加过程记录。
