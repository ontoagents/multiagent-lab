## 板块 1：源论文与拆解材料

### 1.1 Ontology-Guided Long-Term Agent Memory for Conversational RAG ⭐⭐⭐⭐⭐
- **作者/发表**：Shuang Cao, Rui Li（Hill Research）；MLSys 2026
- **链接**：[论文页](https://proceedings.mlsys.org/paper_files/paper/2026/hash/2fb4be70fc9668e9ec2c71b34fb127d4-Abstract-Conference.html) ｜ [MLSys Poster](https://mlsys.org/virtual/2026/poster/3515)（注：无公开代码仓库）
- **核心贡献**：定义"隐式召回失败"问题并构建 Implicit Preference Recall 基准（500 段多会话对话）；提出三件套——Tag2Graph-Learner（数据驱动对话本体学习：标注器+分类器走热路径、LLM 只做验证、门控提升概念边）、Graph×Dense Consistency（只在被验证证据上对齐两模态，分歧 −47%）、Learnable Routing（上下文赌博机按查询分派策略与预算）
- **关键数据**：Recall@10 0.580→0.706，nDCG@10 0.410→0.514；成本较长上下文降 81%；P95 ~185ms；历史扩 8× 延迟 176→189ms；冷启动 0.613 / 成熟画像 0.718；LoCoMo 外部验证 0.576/0.451
- **局限（论文自认）**：冷启动验证覆盖率 19%；提升门限需按域校准；对开放域因果推理与超长程叙事覆盖有限；反馈稀疏退化未充分讨论
- **阅读价值**：本报告的第一研究对象，动态本体运行时构建的"最小完整闭环"范本

## 板块 2：智能体记忆系统（容量与生命周期管理线）

### 2.1 MemGPT: Towards LLMs as Operating Systems ⭐⭐⭐⭐
- **作者/发表**：Charles Packer et al.（UC Berkeley）；2023，arXiv:2310.08560
- **链接**：[arXiv](https://arxiv.org/abs/2310.08560) ｜ [GitHub → Letta](https://github.com/letta-ai/letta)
- **核心贡献**：OS 式分层记忆（主上下文⇄外部上下文），LLM 通过工具调用自主 page in/out；自编辑笔记与档案检索
- **与动态本体的关系**：解决"存取调度"，不提供概念结构；是所有后续记忆系统的架构祖先（2024 年 9 月并入 Letta 平台）

### 2.2 Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory ⭐⭐⭐⭐
- **作者/发表**：Prateek Chhikara et al.（Mem0 团队）；2025，arXiv:2504.19413
- **链接**：[arXiv](https://arxiv.org/abs/2504.19413)
- **核心贡献**：write-manage-read 循环（抽取事实→增/改/删决策→检索接地）成为记忆系统的通用形式化；厂商自报数据：记忆层较全上下文 66.9% vs 72.9%，但延迟 0.71s vs 9.87s、token 1.8K vs 26K
- **与动态本体的关系**：记忆单元独立无类型关联——恰是本体层要补的短板；2025 年 10 月融资 2500 万美元，是图式记忆最直接的竞品路线

### 2.3 A-MEM: Agentic Memory for LLM Agents ⭐⭐⭐
- **作者/发表**：Wujiang Xu et al.（Rutgers）；2025，arXiv:2502.12110
- **链接**：[arXiv](https://arxiv.org/abs/2502.12110)
- **核心贡献**：Zettelkasten 卡片盒式动态记忆组织，笔记间涌现式链接
- **与动态本体的关系**：链接无类型、无 schema 意识，代表"结构化但无本体"的中间形态

### 2.4 MemGen: Weaving Generative Latent Memory for Self-Evolving Agents ⭐⭐⭐
- **作者/发表**：Guibin Zhang, Muxin Fu, Shuicheng Yan；2025，arXiv:2509.24704
- **核心贡献**：纯潜在记忆范式代表——记忆以生成式潜变量形式存在于模型内部
- **与动态本体的关系**：与显式符号本体形成光谱两端；后续混合架构（LatentGraphMem）的重要基线

### 2.5 LatentGraphMem: 隐式图，显式检索 ⭐⭐⭐
- **发表**：2026，arXiv:2601.03417（[alphaXiv 中文页](https://www.alphaxiv.org/zh/abs/2601.03417)）
- **核心贡献**：潜在图记忆 + 显式检索的混合；实验显示纯显式结构（A-MEM/Mem0）在长时序场景不稳定
- **阅读价值**：符号本体 vs 潜在记忆之争的最新回合

### 2.6 Memory Chain（CoM）：动态演进轻量级记忆 ⭐⭐
- **发表**：2026，arXiv:2601.14287（[alphaXiv 中文页](https://www.alphaxiv.org/zh/abs/2601.14287)）
- **核心贡献**：反方向探索——证明"轻量构建+精巧利用"可以胜过重型结构化构建（以 Mem0/A-MEM 为基线，LoCoMo 验证）
- **阅读价值**：对"本体越重越好"的警示；动态本体设计应取轻量路线

### 2.7 What Happens Inside Agent Memory? Circuit Analysis from Emergence to Diagnosis ⭐⭐⭐
- **作者/发表**：Xutao Mao et al.（ CityU HK / U Toronto）；2026，arXiv:2605.03354
- **链接**：[arXiv](https://arxiv.org/html/2605.03354v2)
- **核心贡献**：机制可解释视角：跨 Qwen-3（0.6B–14B）× mem0/A-MEM 追踪特征电路。发现①路由电路 0.6B 即激活，内容接地电路 4B 才出现；②读写共享基座模型已有的接地 hub。无监督阶段级故障定位准确率 76.2%
- **与动态本体的关系**：为"小模型做路由/抽取、大模型做验证/接地"的模型分工策略提供机制层证据

### 2.8 MemAgent: Reshaping Long-Context LLM with Multi-Conv RL-based Memory Agent ⭐⭐
- **发表**：2025，arXiv:2507.02259
- **核心贡献**：RL 训练的记忆管理策略，代表"学习式记忆管理"路线

## 板块 3：图增强检索与运行时图谱引擎（结构化检索线）

### 3.1 From Local to Global: A Graph RAG Approach to Query-Focused Summarization（GraphRAG）⭐⭐⭐⭐
- **作者/发表**：Darren Edge, Ha Trinh et al.（Microsoft）；2024，arXiv:2404.16130
- **链接**：[arXiv](https://arxiv.org/abs/2404.16130) ｜ [GitHub](https://github.com/microsoft/graphrag)
- **核心贡献**：LLM 抽取实体关系图 → Leiden 层级社区检测 → 逐社区 LLM 摘要 → map-reduce 回答全局 sensemaking 问题；Llm-judge 胜率 72–83%（comprehensiveness）
- **与动态本体的关系**：需要**预定义实体类型**（本体静态）；文档变更后社区摘要过时需重建——动态本体要解决的正是这两点；已知修正研究指出其 LLM-judge 胜率在校准后大幅缩水（beancount.io 2026-06 复核），引用数据需谨慎

### 3.2 HippoRAG: Neurobiologically Inspired Long-Term Memory for LLMs ⭐⭐⭐⭐
- **作者/发表**：Bernal Jiménez Gutiérrez et al.（OSU）；NeurIPS 2024，arXiv:2405.14831
- **链接**：[arXiv](https://arxiv.org/abs/2405.14831) ｜ [GitHub](https://github.com/OSU-NLP-Group/HippoRAG)
- **核心贡献**：海马体记忆索引理论 → LLM 建 KG 索引（新皮层）+ Personalized PageRank 单步多跳（海马体）；多跳 QA 超 SOTA 20%，较 IRCoT 迭代检索便宜 10-20×、快 6-13×；被引 800+
- **与动态本体的关系**：证明"图索引优于迭代 LLM 推理"的性价比；但 schema 固定

### 3.3 LightRAG: Simple and Fast Retrieval-Augmented Generation ⭐⭐⭐⭐
- **作者/发表**：Zirui Guo et al.（HKU）；2024，arXiv:2410.05779
- **链接**：[arXiv](https://arxiv.org/abs/2410.05779) ｜ [官网](https://lightrag.github.io/) ｜ [GitHub](https://github.com/HKUDS/LightRAG)
- **核心贡献**：双层检索（低层实体细节/高层主题抽象）+ 实体关系 KV 化 + **增量更新算法**（新文档按同一索引流程并入节点/边并集，免全量重建）
- **与动态本体的关系**：**增量更新机制是运行时图生长的直接技术来源**，可直接移植

### 3.4 MemoRAG: Boosting Long Context Processing with Global Memory-Enhanced Retrieval Augmentation ⭐⭐⭐
- **作者/发表**：Hongjin Qian et al.（智源研究院+人大）；theWebConf 2025，arXiv:2409.05591
- **链接**：[arXiv](https://arxiv.org/abs/2409.05591) ｜ [GitHub](https://github.com/qhjqhj00/MemoRAG)
- **核心贡献**：轻量长程 LLM 建全局记忆（KV 压缩形态，RLGF 反馈强化）→ 生成草稿线索 → 引导检索 → 强 LLM 作答；针对"模糊查询表述+非结构化知识"场景
- **与动态本体的关系**：全局记忆的"压缩记忆"路线，与符号图谱路线互补对照

### 3.5 Zep: A Temporal Knowledge Graph Architecture for Agent Memory ⭐⭐⭐⭐⭐
- **作者/发表**：Preston Rasmussen et al.（Zep AI）；2025，arXiv:2501.13956
- **链接**：[arXiv](https://arxiv.org/abs/2501.13956) ｜ [Graphiti GitHub](https://github.com/getzep/graphiti)
- **核心贡献**：三层子图（episode 无损层→语义实体层→社区层）+ **bi-temporal 双时间线**（事实时间/记录时间）+ 矛盾边失效化（invalid_at 而非删除）+ 标签传播社区动态更新；四消息窗口实体抽取 + 混合相似度去重
- **关键数据**：DMR 基准 94.8–98.2%；LongMemEval（gpt-4o）71.2% vs 全上下文 60.2%，延迟 2.58s vs 28.9s（上下文 115K→1.6K token）；单会话偏好 20.0%→56.7%
- **与动态本体的关系**：**自称"self-building ontology"**（自动识别实体类型并映射演化关系），是目前最接近"运行时动态本体"的生产级开源实现
- **配套资料**：[451 Research 覆盖报告 PDF](https://www.getzep.com/downloads/451Research_Reprint_ZepSoftware_10APR2026.pdf)（2026-04，含 Graphzilla 企业平台、context lakehouse 架构、ABAC 治理、竞品格局）；[Graphiti 技术研究报告（代码级分析）](https://lin-guanguo.github.io/llm-memory-research/graphiti.research/)

## 板块 4：动态 schema 归纳与本体演化（动态本体的直接文献基础）

### 4.1 AutoSchemaKG: Autonomous KG Construction through Dynamic Schema Induction from Web-Scale Corpora ⭐⭐⭐⭐⭐
- **作者/发表**：Jiaxin Bai et al.（HKUST KnowComp + 华为）；2025，arXiv:2505.23628
- **链接**：[arXiv](https://arxiv.org/abs/2505.23628) ｜ [GitHub](https://github.com/HKUST-KnowComp/AutoSchemaKG)
- **核心贡献**：**零预定义 schema**：LLM 同时抽三元组+归纳 schema；实体+事件双建模（事件信息保留 90% 段落内容 vs 仅实体 70%）；概念化（conceptualization）机制把实例泛化为语义类别层级
- **关键数据**：5000 万文档 → ATLAS 图谱族（9 亿节点/59 亿边）；**schema 归纳与人工 schema 语义对齐 92–95%（零人工）**；多跳 QA 超 SOTA 12–18%；事实性提升至 9%
- **与动态本体的关系**：**"动态本体可行性"的最强单篇证据**——证明 LLM 归纳的 schema 已达专家质量，且可扩展到亿级

### 4.2 EDC: Extract-Define-Canonicalize（Zhang & Soh, 2024）⭐⭐⭐⭐
- **核心贡献**：开放信息抽取 → 自由形式语义定义 → schema 规范化三段式；可将自动归纳 schema 对齐已有本体，或在无预定义结构时新建
- **与动态本体的关系**：**"本体规范化/合并"环节的标准做法**——对应本报告架构中的类型收敛模块
- **检索入口**：arXiv:2404.03290（Towards Knowledge Graph Schema Expansion with LLMs）

### 4.3 AdaKGC: Adaptive Knowledge Graph Completion（Ye et al., 2023）⭐⭐⭐
- **核心贡献**：动态 schema 演化——纳入新关系类型/新实体类型**无需重训模型**
- **与动态本体的关系**：证明 schema 扩展与模型训练解耦，是"运行时加类型"的早期可行性证明

### 4.4 Agentic-KGR: Co-evolutionary Knowledge Graph Construction through Multi-Agent RL ⭐⭐⭐⭐
- **作者/发表**：Haijia Sun et al.；2025，arXiv:2510.09156
- **链接**：[arXiv](https://arxiv.org/abs/2510.09156)
- **核心贡献**：LLM 与 KG 通过多轮 RL **协同演化**；动态 schema 扩展机制系统性地把本体扩展到预定义边界之外；**staged relation promotion（分阶段关系提升）**——新关系先暂存后提升，平衡新颖性与一致性；置信衰减 + 老化机制；Neo4j 唯一约束去重 98.5%；事务批量 upsert 提速 30%
- **与动态本体的关系**：分阶段提升 + 置信衰减是原论文门控机制的多智能体强化版，适合高吞吐场景参考

### 4.5 Agentic Deep Graph Reasoning Yields Self-Organizing Knowledge Networks（Buehler, MIT）⭐⭐⭐
- **作者/发表**：Markus J. Buehler（MIT）；Journal of Materials Research 2025
- **链接**：[MIT DSpace](https://dspace.mit.edu/entities/publication/5ee4496a-5a11-4108-8dac-045bc4e5ec52)
- **核心贡献**：推理原生 LLM + 持续更新图谱的反馈循环；每步生成新概念/关系、并入全局图、基于演化结构构造下一步提示。数百轮迭代后图谱呈**无标度网络**（hub 形成、模块稳定、桥接节点连接异质簇），节点/边持续增长不饱和
- **与动态本体的关系**：从复杂网络理论证明**自组织图谱的数学稳定性**——回答"一直加节点会不会乱掉"的担心

### 4.6 Ontogenia / CQbyCQ / LLMs4OL / NeOn-GPT（LLM 辅助本体工程群）⭐⭐⭐
- **要点**：Metacognitive Prompting 生成 OWL 本体（自反思+结构修正）；CQbyCQ 把能力问题/用户故事直接转译为 OWL schema；LLMs4OL 验证 LLM 的概念识别/关系抽取/模式归纳能力；NeOn-GPT 提供端到端本体构建工作流
- **结论性证据**（Lippolis et al. 2025）：LLM 自主识别类/对象属性/数据属性并生成逻辑公理，质量与初级人类建模者相当
- **与动态本体的关系**：种子 schema 的人机协作生成方法（对应本报告阶段 1）

### 4.7 Evontree（本体自适应演进）⭐⭐
- **要点**：把 LLM 视为隐式知识库，少样本挖掘其内部子类/同义词知识 + 少量专家本体规则外部验证 + 自蒸馏生成 QA 对微调回注
- **与动态本体的关系**：**冷启动阶段的本体先验注入**候选方案（本报告开放问题 #1 的对策参考）

### 4.8 RAKG: Retrieval Augmented Knowledge Graph Construction ⭐⭐
- **要点**：检索增强的 KG 构建，抽取时带结构约束校验过滤幻觉
- **与动态本体的关系**：M2 模块（证据抽取验证）的幻觉过滤参考

### 5.3 Agentic Knowledge Graphs: A Comprehensive Review（行业综述）⭐⭐⭐

- **阅读价值**：产业视角补 academic 综述之缺

### 5.4 Agentic Symbolic Knowledge Generation（Anthony Alcaraz, 2025）⭐⭐
- **链接**：[博客](https://blog.solega.co/agentic-symbolic-knowledge-generation-the-future-of-ai-knowledge-systems-by-anthony-alcaraz-apr-2025/)
- **亮点概念**：动态本体选择（系统判断现有本体覆盖度，不足则提议新本体）；**元本体（meta-ontology）**——"关于本体的知识图谱"，捕获本体间关系、支持继承与模板化，构成自我改进生态

### 5.5 持续学习与动态更新：AI 知识库自我演进技术综述（中文）⭐⭐
- **链接**：[LumeValley](https://www.lumevalley.com/article-5011.html)
- **亮点**："智能体无法学习它无法命名的东西"；**本体漂移（ontology drift）**概念——静态分类体系在业务/技术演进下失效；结论：记忆管理与本体动态演进本质同源
- **阅读价值**：中文语境下对 R1 风险（本体漂移）的最好表述

## 板块 6：评测基准与质量保障

### 6.1 LoCoMo: Evaluating Very Long-Term Conversational Memory of LLM Agents ⭐⭐⭐⭐
- **作者/发表**：Adyasha Maharana et al.（UNC）；ACL 2024，arXiv:2402.17753
- **链接**：[arXiv](https://arxiv.org/abs/2402.17753)
- **构成**：50 段超长对话（均值 300 轮/9K tokens，最多 35 会话）；机器-人混合生成管线（persona + 时序事件图接地 + 人工校验）；三类任务（QA/事件摘要/多模态对话）
- **注意**：广泛引用的是 10 段/1986 题子集，完整版为 50 段/7512 题——跨论文对比需核对 harness

### 6.2 LongMemEval ⭐⭐⭐⭐
- **作者/发表**：Wu et al.；ICLR 2025，arXiv:2410.10813
- **构成**：500 题精标实例，平均 115K tokens；五能力轴（信息抽取/单会话用户&助手/单会话偏好/多会话/知识更新/时序推理）；商业助手平均掉约 30 分
- **阅读价值**：目前最难也最贴近企业负载的记忆基准；Zep/原论文均用作外部验证

### 6.3 BEAM ⭐⭐⭐
- **作者/发表**：Tavakoli et al.；2025，arXiv:2510.27246
- **构成**：对话最长达 **10M tokens**，考察能力含矛盾消解、事件排序等 10 项；1M 窗口模型亦不能胜任
- **阅读价值**：给"堆窗口"路线的盖棺定论

### 6.4 MemoryAgentBench ⭐⭐⭐
- **作者/发表**：Hu et al.；2025，arXiv:2507.05257
- **构成**：含冲突消解/选择性遗忘专项
- **阅读价值**：补充本体演化系统的"废退能力"评测

### 6.5 Learning What Not to Forget ⭐⭐
- **发表**：2026，arXiv:2606.20954
- **核心贡献**：query-agnostic 的记忆相关性预测（几 KB 参数的轻量模型），LoCoMo 上以 LOGO 协议做无泄漏评测
- **阅读价值**："遗忘/驱逐"侧的最轻量方案，可作 M6 维护模块的补充

### 6.6 评测方法论提醒（跨论文横向对比须知）
- vendor 自报分数普遍偏高（Mem0 2026-06 自报分被标注 flag）；
- LLM-as-judge 选择可造成两位数波动（GraphRAG 72–83% 胜率在校准后大幅缩水）；
- 无中立 leaderboard，同一基准名可映射不同数据集（LoCoMo 完整版 vs vendor 子集）；
- **本报告引用的论文数据均标注了原始出处与 harness 差异，横向对比时请以"统一预算+统一延迟护栏"的重测为准**（原论文的做法值得效仿）。

## 附 A：术语表

| 术语 | 定义 |
|---|---|
| 隐式召回失败（implicit recall failure） | 当前查询与历史证据无词汇重叠时，稠密检索/长上下文漏召相应记忆的失效模式 |
| 动态本体（dynamic ontology） | 运行时自动归纳、持续演化的类型系统+实例图+演化机制三件套 |
| schema 归纳（schema induction） | 从实例数据中自动抽象概念类别与关系类型的过程（data-to-schema） |
| 概念化（conceptualization） | AutoSchemaKG 的实例→语义类别泛化机制，构建类型层级 |
| 提升门控（promotion gate） | 断言入本体/入图前的多信号校验机制（复现×一致×兼容×门限） |
| bi-temporal 双时间线 | 同时追踪事实发生时间（valid time）与记录时间（transaction time） |
| 边失效化（edge invalidation） | 新事实矛盾时给旧边打 invalid_at 时间戳而非删除，保留可查询历史 |
| 本体漂移（ontology drift） | 静态分类体系随业务演进失效、新知识无处归类的现象 |
| 分阶段关系提升（staged relation promotion） | 新关系先暂存观察、再正式提升的演化协议（Agentic-KGR） |
| 无标度网络（scale-free network） | 度分布幂律的网络结构；Buehler 证明自组织图谱收敛于此，稳定性证据 |
| graph-first / dense-first | 检索策略：图遍历领先 vs 稠密检索领先，由可学习路由器按查询分派 |
| 反事实重放（counterfactual replay） | 离线模拟同一预算下替代检索策略以训练路由器 |
| 元本体（meta-ontology） | 描述本体之间关系的知识图谱，支持本体继承与模板化生成 |
