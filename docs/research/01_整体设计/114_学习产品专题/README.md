## 2. 三方合成结论（两档合并后的总判断）

```
外部材料（论文/教材/文档/音视频/主题）
   ↓ ① 学习过程【OpenMAIC 生成管线 × DeepTutor 交互组织】
学习大纲 → 逐节精讲/互动演示 → 自测 → 追问探究 → 课题实践
   ↓ ② 沉淀【本项目独有】笔记本/本体(停车场 REQ-573)/KG/KB
   ↓ ③ 消费【本项目独有】RAG/GraphRAG · SparQL · 定向出题 · 掌握度 · 审计
   ↓ 回到 ①：薄弱概念定向出题 → 再学习（REQ-572 闭环）
```

- OpenMAIC=「生成即消费」范式（课程是演出脚本不是资产，RAG 仅内存词法索引）；DeepTutor=有知识中心但无本体结构（91 号 §3）；**本项目独占 ②③ 后半环**——借鉴=把学习过程引擎接到资产底座上。
- 对账结论：**消费环已齐、学习过程环半齐、沉淀缝合层（学习会话→本体/笔记本/KG 一键落库）是最大空白**=「学习利器」成立前提（115 号 §4.4）。
