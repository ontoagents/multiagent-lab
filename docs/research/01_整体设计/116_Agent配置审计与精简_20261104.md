# 项目 Agent 配置审计与精简

本档记录 2026-11-04 开发者授权的配置重构，属于开发治理，不新增产品 REQ。现行规则入口是 [AGENTS.md](../../../AGENTS.md)，治理记录见 [18 注册表](../../18_REQ编号注册表.md) G-8；验证结果见 [20 冒烟清单](../../20_回归冒烟清单.md) 4.287。本档是审计材料，不向后续任务追加执行步骤。

## 1. 官方依据与适用范围

2026-11-04 实际获取并阅读了以下 OpenAI 官方页面。网页搜索工具本轮没有返回内容，随后通过 HTTPS 获取原文；未将检索失败解释为模型或文档不存在，也未更改项目模型默认值。

- [GPT-6 Astra：Prompting best practices](https://developers.openai.com/api/docs/guides/latest-model/gpt-6-astra.md#prompting-best-practices)：明确指出模型对 Skills/AGENTS 指令较敏感，模糊或冲突的指导可能导致提前停工；建议沿任务意图完成工作、利用已有授权，并按风险选择验证。
- [Codex Skills](https://developers.openai.com/codex/skills)：描述应简洁、有明确适用边界；发现阶段只加载名称和描述，使用时才读正文，进一步资料按需读取。
- [AGENTS.md](https://developers.openai.com/codex/guides/agents-md)：项目指令按目录作用域加载；默认组合体量限制为 32 KiB。原仓库 AGENTS.md 为 36,911 字节，超过该默认值，且历史条目并不适合常驻上下文。

这些是配置设计依据，不构成模型效果保证。本轮修改仓库内文件；用户全局 Skills、插件缓存、账户配置、其他项目不在修改范围内。运行平台仍可能注入全局指令，仓库配置无法替代平台权限。

## 2. 盘点与处置

扫描包含隐藏目录的仓库文件、已跟踪指令文件，以及代码内的提示词与技能装配点。没有第二份仓库 AGENTS.md、CLAUDE.md、GEMINI.md、Cursor/Copilot 指令或开发 SKILL.md。

| 文件/入口 | 审计结论与处置 |
| --- | --- |
| 根 AGENTS.md | 删除重复交付流水、无条件 fetch/提交/push、自合、全库压缩和强制读档委派；保留技术边界、数据与审批保护、需求登记、适量验证；增加本地自主执行及完成标准 |
| `.agents/skills/onto-dev/SKILL.md` | 唯一仓库开发 Skill；description 缩为 REQ 立项/交付回写/文档归区三个具体触发；根文件只路由到需求、交付参考及现有文档导览 |
| CONTRIBUTING、PR 模板、docs 各区 README | 统一新能力与恢复既定行为修复的边界、按需回写/验证、远程授权；修复受影响的相对链接，移除复制 Skill 的建议 |
| `hooks/pre-commit`、`tools/docsize.sh` | 保持 doccheck 门禁；删除自动跳过门禁的建议；体量提示限定当前改动，避免旧档超限迫使任务无限扩张 |
| 18 治理记录、20 冒烟导读 | 旧制度留史并标明演进；冒烟按改动面选，不再要求所有交付全跑主链路 |

## 3. 规则场景回归

重构前只读代理按旧文件推演了三类任务，发现纯链接修复仍被要求 fetch/提交/push、存在他人改动时“清空未提交”易扩大范围、新增能力被当作远程自合授权。以下为新规则的验收案例；它们检查规则决策，不替代实际产品测试，也不是 GPT-6 Astra 多次采样评测。

| 场景 | 预期行为 |
| --- | --- |
| 修正文档链接 | 直接修改、检查链接与文档门禁；不领号、不读全部架构、不跑全站 UI、不自动推送 |
| 明确本地 bug、工作区有他人改动 | 保留他人改动，定位修复并验证受影响项；恢复既定行为沿已有 REQ，不强制重建计划/worktree |
| 新增跨模块产品能力、未授权远程 | 按需读需求与相关现状、领号和回写，完成本地实现及验证；远程写操作独立取得授权 |
| 用户已明确授权本次配置重构 | 直接完成范围内编辑；不因“大规模重构”标签反复要求同一授权 |
| 受影响测试失败 | 查因并修复本次问题，重新验证；不可把跳过当作通过，也不自动绕过 hook |
| 需要读取部署配置但未授权修改环境 | 可只读定位，配置变更前说明具体动作；其他本地工作继续 |

最终验证命令及实际结果集中在 20 号 4.287；未进行模型迁移、真实远程写操作或产品运行时行为改动。
