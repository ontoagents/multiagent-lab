# 交付回写

仅在交付或准备提交时读取。验证和权限以 [AGENTS.md](../../../../AGENTS.md) 为准；本表按实际改动选择，不是每个任务都要改全部账本。

| 改动 | 必要记录 |
| --- | --- |
| 已有需求的产品实现/修复 | 对应需求档迭代表、[20 验证记录](../../../../docs/20_回归冒烟清单.md)；需求行用简短指针 |
| 完成或关闭开放 REQ | [18](../../../../docs/18_REQ编号注册表.md) 注册行迁 [18A](../../../../docs/18A_REQ归档册.md)，[19](../../../../docs/19_REQ状态索引.md) 移出并更新计数；只有验证完成才能标交付 |
| 批次/跨模块里程碑 | 更新 [02 §12](../../../../docs/02_智能体_技术方案设计.md)；单件不额外建行 |
| 产品能力/行为/决策变化 | 更新对应 handbook 现状档的实际归属表；记录当前能力与限制 |
| 开发治理规则变化 | 更新治理档及受影响指引；不改产品能力表，不新领产品 REQ |
| 笔误、链接等纯文档小修 | 检查修改与引用；不用回写所有账本 |

## 验证与交付

- 选受影响包/页面验证；运行结果须实际检查，修复失败后重跑受影响检查。并发修改使用相应包的 `-race`，前端动线修改按 20 号对应节冒烟。无产品行为变化不强制跑全站 UI。
- 文档与 Agent 配置检查引用路径、Skill 触发范围及权限冲突；提交前运行 `cd backend && go test -count=1 ./internal/doccheck`。`bash tools/docsize.sh` 用于查看体量，旧档超阈值不扩成无关清理任务。
- 使用隔离测试数据；本轮临时夹具可自行清理，勿修改真实数据库或删除用户数据。日志和截图留在被忽略的 `smoke/`。
- 区分本任务与既有改动，确认本任务 diff 符合预期；提交时只包含本任务改动，共享文件提交前核对并行更新。按用户的提交约定处理本地 commit；推送、PR 创建/合并等远程写操作遵守已有授权，不能由 Skill 自动授权。
- 失败无法在授权范围内解决时，记录实际阻塞和未验证项，完成可继续部分；不得伪造通过或自动跳过门禁。完成判据见 AGENTS.md「完成标准」。
