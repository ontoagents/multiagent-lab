智能体构建平台（Windows 桌面安装版）
=====================================

快速上手
--------
1. 双击「智能体构建平台」（开始菜单或桌面快捷方式）：会自动启动本地服务并打开平台窗口。
2. 首次使用请进入「设置」→「模型连接」配置一个大模型 API（OpenAI 兼容端点），智能体对话与
   本体 AI 构建依赖该连接；不配置也可浏览学习中心、平台知识等本地内容。
3. 关闭平台窗口即停止全部后台服务（数据已落盘，不会丢失）。

数据与日志
----------
- 数据目录：安装目录\data\（SQLite 数据库、项目文件、引擎数据、伴生快照）——安装器已把该位置
  写入 data.location 供启动器读取；数据随安装目录走（装在其他盘则数据同样不占 C 盘）。
  备份 = 停止服务后复制整个 data\ 目录（换机迁移请连同 data\.secret 一起带走）。
- 服务日志：安装目录\data\logs\（backend.log / ontology-service.log / runtime-manager.log）。
- 卸载程序不会删除数据目录：数据保留，彻底清理请手动删除安装目录。
- oxigraph 引擎不随包分发（减小安装包体积）：首次使用本体「运行」功能时，
  在运行页「引擎未安装」提示中一键下载安装（自动落位即时生效）。

端口占用
--------
本安装固定使用本机端口 8080（平台）/ 8091（本体构建平面）/ 8090（本体运行平面），
oxigraph 引擎子进程从 9201 起动态分配。若与其他程序冲突，启动时会明确报错。

能力边界（诚实声明）
--------------------
- 本体导入导出（OWL/TTL 格式）依赖系统 Python3 + rdflib：未安装时该功能不可用并会给出
  提示，平台其余功能不受影响。
- 知识库向量后端默认使用内置 SQLite（零依赖）；如需 Qdrant，可在启动环境中覆盖
  KB_VECTOR_BACKEND=qdrant 并配置 QDRANT_URL。
- 智能体沙箱执行（Docker 容器形态）不在本安装包内：需要 Docker Desktop 并自行配置。
- 本安装为单机单实例：不支持同时运行多个平台副本。
